# Решение для задачи NER в текстах fashion-тематики

В данной работе рассмотрены варианты решения задачи выделения именованных сущностей в текстах fashion-тематики  
Задача: распознавать характерные именованные сущности в области fashion (одежда и аксессуары - тэг ITEM, признаки/характеристики - тэг FEAT, события/поводы/контекст - тэг EVENT ) в формате разметки BIO.  

  
Датасет собран комбинированным способом: парсинг соцсетей, ручная разметка (LabelStudio) + генерация LLM.  
В качестве решений было выброно нескольких алгоритмов (SpaCy NER, RNN/GRU, RNN/LSTM, BERT finetuning)  и проведен ряд экспериментов.

В ходе проделанных экспериментов лучшие метрики показала модель на основе архитектуры BERT: f1-score = 95% и имеющая 35М параметров. 
Для приложений с ограниченными вычислительными ресурсами в качестве альтернативы может быть использована более легкая модель (745К параметров) на основе архитектуры RNN с ячейкой GRU:  f1-score = 94%

Использованные технологии: LabelStudio, Pytorch, SpaСy, RNN, GRU, LSTM, Transformers, BERT, Finetuning, Matplotlib
