# Решение для задачи NER в текстах fashion-тематики

В данной работе рассмотрены варианты решения задачи выделения именованных сущностей в текстах fashion-тематики

Разработана модель на основе предобученного трансформера с метрикой f1-score = 95%

Использованные технологии: LabelStudio, pytorch, Spacy, RNN, GRU, LSTM, transformers, BERT, Finetuning, matplotlib
